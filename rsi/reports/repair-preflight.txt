一、结论

P0-1（生产 preflight 无法启动、cwd 位于 protected 源码树）已修复，并由真实本地子进程测试覆盖：
- MappedPreflightLauncher 与 SandboxLauncherPreflight 都显式使用 process.execPath 作为 executable，并把 .ts 入口放入 args。
- runChild 使用 /tmp/rsi-preflight/<uuid>/cwd 这类实际存在、可被 Worker UID 进入、且不在 protected/hidden root 的专用 staging cwd。
- candidate、result、stderr 的宿主到 sandbox 路径映射按相对路径生成 POSIX 路径；临时目录在静态/Mock 子进程结束后删除。
- LocalProcessGroupLauncher 正确处理显式 executable/args，不再对预检入口重复套 Node，也不丢参数。

这不是完整 RSI 验收通过：真实 Linux/bwrap 仍未在本机执行验证；old integration 报告早于最新失败回归，不能据其宣称全绿。全量 rsi 测试仍有 10 个失败，均属于本次独占范围之外的旧缺陷。不得把本报告的 argv/staging 单元或本地 launcher 结果当作真实 bwrap 通过。

二、根因与修复

根因：
1. rsi/src/integration/reload-service.ts 的 MappedPreflightLauncher 和 rsi/src/reload/preflight-runner.ts 的 SandboxLauncherPreflight 只传 workerEntry=.ts，不设置 executable/args。Linux bwrap 直接 exec 无 shebang 的 0644 .ts 源文件，必然 EACCES/ENOEXEC；Windows LocalProcessGroupLauncher 自动用 node 包装，掩盖了问题。
2. runChild 把 cwd 设为 dirname(workerEntry)，即 protected 的 rsi/src/reload/workers。沙箱 plan 会以 SANDBOX_ALIAS_RISK 拒绝 protected cwd，导致首次 baseline 和所有 reload preflight 走同一失败路径。

修复文件与行为：
- rsi/src/integration/reload-service.ts
  - MappedPreflightLauncher.launch 固定 executable=process.execPath、args=[绝对入口路径]。
  - 增加安全 cwd 选择：调用方传入的 protected/不存在 cwd 会被替换到专用 staging 目录，不再进入 RSI 源码树。
  - candidate manifest 映射到 /run/rsi-plugins/...；result/stderr 按相对于宿主临时目录的路径映射到 /run/rsi-preflight/<uuid>/...，不再硬编码文件名。
  - sandbox 路径统一用 POSIX path 生成；非沙箱本地入口仍保留宿主原生路径，避免 Windows 回归。
- rsi/src/reload/preflight-runner.ts
  - 新增 ensurePreflightWorkingDirectory：拒绝 worker 入口源码目录、policy protected/canonicalProtected/hidden 以及真实路径指向这些 root 的 cwd；必要时使用调用方 staging parent 或 OS 预检 staging root。
  - SandboxLauncherPreflight 同样固定 Node executable + [入口] argv，并先解析安全 cwd。
  - runChild 默认临时根从 snapshotDir（hidden control state）改为 OS 临时目录下的 rsi-preflight；每个子进程使用独立 <tempRoot>/<uuid>/cwd。
  - tempRoot 设为可遍历（0711），子临时目录和 cwd 设为 0777 以允许独立 Worker UID 写入；每个子进程结束后删除整个临时目录。
  - 保留静态检查有界、Mock 硬 3000ms 截止、超时对 handle 终止并调用 launcher.killTree、失败 result.stack 返回工具报告。
  - 读取 result/stderr 改为 lstat 常规文件、拒绝 symlink 和多硬链接、O_NOFOLLOW（平台支持时）并核对打开前后 dev/ino/nlink，避免读取子进程伪造的别名目标。
- rsi/src/reload/process-tree.ts（必要的 reload 预检/本地启动代码）
  - LocalProcessGroupLauncher 支持显式 executable/args：显式 executable 时直接使用完整 args，不再默认 prepend process.execPath；无 executable 的旧本地 Worker 路径仍保持 node [workerEntry, ...args]。
  - 显式 executable 但 args 为空时，仅在 executable 与逻辑 workerEntry 不同时补入 workerEntry，避免丢掉入口。
- 测试
  - 保留并强化 rsi/test/acceptance/preflight-child-executable.test.ts：继续检查 executable/args/cwd 不在 protected RSI 源码，并新增 cwd 不位于入口源码目录、目录实际存在。
  - 新增 rsi/test/acceptance/preflight-launch-contract.test.ts：
    * 两个适配器均使用 Node+argv 且 cwd 实际可用、安全。
    * Mapped sandbox 路径映射 candidate/result/stderr 与 mounts。
    * 真实静态解析 + 真实 Mock 子进程使用独立 staging cwd，结束后清理。
    * 本地 launcher 显式 executable 不重复套 Node、不丢空参数/含空格参数；旧式无 executable 路径仍工作。
    * 顶层 while(true) 的 Mock 超时后，候选启动的孙进程一并被杀死。
  - 新增 rsi/test/integration/runtime-reload-preflight-start.test.ts：首次 baseline 正常建立，随后普通 reload 经外部 preflight 成功加载插件。
- rsi/reports/repair-preflight.txt：本报告。

- 没有执行真实 Linux bwrap 的首次 baseline、reload preflight、Worker UID 权限、result/stderr mount、静态/Mock 子进程启动。
- 没有执行 Docker/Compose build/up/healthcheck、seccomp/AppArmor/setpriv、卷恢复或 24H 运行。

五、需要集成接线/后续处理的事项（跨范围）

1. integration/runtime.ts 当前已使用 MappedPreflightLauncher 并传 tempRoot=/tmp/rsi-preflight，本次无需改 runtime 即可走新逻辑。Linux 集成需确认容器内 /tmp/rsi-preflight 由 Supervisor 创建且可被 Worker UID 遍历；预检子目录由本实现按 0711/0777 处理并在每次子进程后删除，根目录仍由 runtime 保留。
2. 真实 bwrap Linux e2e 应加入首次 baseline、reload preflight、while(true) 超时和子进程树清理断言，并在报告中明确区分 argv/本地 launcher 测试。
3. 上述 10 个剩余失败属于 final-audit 的 provider guard、reload 失败回滚、system prompt、managed alias、sleep heartbeat、metadata、IPC 认证、Watchdog host PID 等旧模块问题，需要各自范围内的实现修复；本报告不把它们视为通过。
4. 本次对 result/stderr 读取增加了 no-follow/硬链接拒绝作为预检诊断加固，但若集成还需要“专用 root-owned 诊断目录/更严格的父进程诊断策略”，应在 IPC/诊断边界范围内继续接线；本次未修改 sandbox/**、IPC 或共享 package。
5. Windows 上仍可能受候选入口绝对路径长度影响；本次已消除 cwd 继承入口长路径的问题，但未改变 candidate snapshot/入口路径本身的长度策略。

最终判定（仅针对 P0-1 预检启动阻塞）：代码与本地真实子进程回归通过；完整 RSI 独立验收仍为不通过，Linux bwrap 与剩余旧缺陷未验证/未修复。
